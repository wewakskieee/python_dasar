# Python Dasar

Kumpulan kode latihan dari materi **Python Dasar** (11 bab).

## Struktur
- `bab01` – Pengenalan Python
- `bab02` – Variabel & Tipe Data
- `bab03` – Input & Output
- `bab04` – Operator
- `bab05` – Percabangan
- `bab06` – Perulangan
- `bab07` – List, Tuple, Set & Dictionary
- `bab08` – Function
- `bab09` – Error Handling
- `bab10` – Module & Package
- `bab11` – Pengolahan Data Sederhana

## Cara menjalankan
```bash
cd bab01
python hello.py
```
(Bab 11 harus dijalankan dari dalam folder `bab11`, dan bab 10 `proyek` dari dalam folder `proyek`.)

Catatan: `bab05/match.py` butuh Python 3.10+, `bab11/pakai_pandas.py` butuh `pip install pandas`.
